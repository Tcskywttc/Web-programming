# Web编程

第八周：在数据驱动 Todo 上实现事件委托、互斥分流与编辑功能。

## 运行

在仓库根目录运行 `python3 -m http.server 8008 --bind 127.0.0.1`，然后打开 `http://127.0.0.1:8008/#todo`。

## 本周功能

- 父容器统一处理列表点击，动态新增任务无需重新绑定监听器。
- 点击文字切换状态；删除、编辑和切换互斥，点击列表空白处直接返回。
- 编辑保留完成状态，取消、空白和未改变的输入不会更新数据。
- 保留添加、筛选、统计、持久化和键盘操作；W8 使用独立存储键。

主要代码为 `index.html`、`style.css` 和 `script.js`，页面资源位于 `images/` 和 `assets/`。
开发分支为 `feature/v2-event-delegation`，阶段提交分别实现操作标识、事件委托和编辑功能。
仓库中原有的 W7 日志、PLAN.md 和 evidence 文件为上周历史材料。
