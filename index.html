基于 YOLO-OBB 与 PaddleOCR 的口算作业自动批改系统 Automatic Arithmetic Homework Grading System

2025 年 11 月至 12 月

An arithmetic homework grading system combining oriented object detection, OCR, and recognition correction.

技术栈 Tech Stack

  • Python
  • PyTorch
  • OpenCV
  • PaddleOCR
  • Gradio
项目背景 Problem
真实作业照片存在倾斜、透视变形与密集算式框；小数点、乘除号和数字“1”的 OCR 误识别会影响最终判分。
我的方法 Approach
将水平框标签转换为旋转框，使用旋转、透视及图像质量增强训练 YOLO11n-OBB；对检测区域透视裁剪并预处理后接入 PP-OCRv5，再用运算符归一化、字符白名单和常见误识别修正规则完成识别与判分。
项目结果 Result
主线模型在验证集上达到 mAP50 0.9938、mAP50-95 0.8165；检测约需 0.02–0.05 秒/张，完整识别与判分约需 0.4–0.5 秒/张。使用 Gradio 展示错题标注、反馈记录与性能报告，并搭建 ONNX、INT8 量化及 30% L1 剪枝的部署对比流程。

多特征融合图像检索系统 Multi-Feature Image Retrieval System

2026 年 6 月

An image retrieval system that combines deep, color, texture, and dHash features for similarity ranking.

技术栈 Tech Stack

  • Python
  • PyTorch
  • OpenCV
  • Streamlit
项目背景 Problem
单一颜色、纹理或哈希特征难以稳定表达图像类别；不同特征的数值尺度也会影响融合排序，查询图参与排序则可能抬高评价指标。
我的方法 Approach
基于 Imagenette 构建 10 类、1000 张图片的检索库，微调 ResNet18 并提取 512 维深度特征；分别归一化深度、HSV、LBP 和 dHash 特征后加权融合，排除查询图，再按余弦相似度排序。
项目结果 Result
在 5 张查询图上的平均 Precision@20 为 1.0000、Recall@20 为 0.2020；使用 Streamlit 实现可配置特征类型、查询图片与 Top-K 的检索展示和指标对比。ResNet18 的最佳验证准确率为 96.5%。
